预览与 Source

文档预览、公开画廊和本机 Source 各自能看什么。

三处不要混用：

入口能看什么不能当成什么
本站组件页真实组件的交互预览、生成的属性、有映射时的 Figma授权、提交成功或设计验收
公开画廊Web Demo、Mobile 目录、主题页。公开版是 Preview本机 Source、规范定稿
仓库 yarn devhttp://127.0.0.1:5173/，本机保留 Source公网地址。localhost 需要本机服务

公开画廊的 Web 哈希是组件名，例如 #PromptInput、#DataGrid、#AppLayout。Mobile 是 #Mobile/Button。Cube 主题页是 #Theme/cube。

文档站的 Foundation 预览在 apps/docs/src/previews/foundation，导入 @heroui/react。Cube 预览复用 packages/example 的 Demo。

Figma 节点只维护 apps/docs/data/figma-pages.json。没有同名条目时，页面不猜测链接。
