- 分层：Cube

- 状态：建设中

## Import

```tsx
import { LoadingState } from "@bosagent/cube-ui/loading-state";
import { LoadingState } from "@bosagent/cube-ui";
```

## Props

## 属性

| 属性 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `label` | `string` | 否 | `"Loading"` | Status text. Rendered with a shimmer while motion is allowed. |
| `showElapsed` | `boolean` | 否 | `true` | Show the live elapsed time beside the label. |
| `startedAt` | `number` | 否 | `—` | Epoch milliseconds when the work started. Omit to start when this mounts. |
| `variant` | `PixelLoaderVariant` | 否 | `"drive"` | Pixel wave passed to the grid. Surfer is not a Cube variant. |
| `className` | `string` | 否 | `—` | — |
| `slot` | `string` | 否 | `—` | — |
